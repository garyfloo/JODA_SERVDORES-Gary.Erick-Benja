Crear el contenedor Mysql
sudo docker run -d \
  --name wordpress-db \
  --network wordpress-net \
  -v mysql-data:/var/lib/mysql \
  -e MYSQL_ROOT_PASSWORD=... \
  -e MYSQL_DATABASE=wordpress \
  -e MYSQL_USER=wordpress \
  -e MYSQL_PASSWORD=... \
  mysql:8.0
  
  
  
  ____docker run     ---Crea y ejecuta un contenedor a partir de una imagen
  
  
  ____--name wordpress-db     ---le damos nombre al contenedor
  en nuestro caso se llama wordpress-db
  
  ____--network wordpress-net    ---conecta el contenedor a nuestra red
  
  
  ___-v mysql-data:/var/lib/mysql	---conecta el volumen
  
  
  
  --------------------------------------------------------
  ___-e        permite establecer variables de entorno dentro del contenedor.
  por ejemplo:
  ___-e MYSQL_DATABASE=wordpress       ---le indica a la imagen de MMysql que cree una base de datos llamada wordpress
  
  tambien usamos
  ___-e MYSQL_USER=wordpress
  
  para crear el usuario de Mysql 
  
  ___-e MYSQL_PASSWORD=...
  
  para estalecer su contraseña
  
  -e MYSQL_ROOT_PASSWORD=...
  
  
  
  RESUMEN
MYSQL_ROOT_PASSWORD
        ↓
Contraseña del administrador root

MYSQL_DATABASE
        ↓
Base de datos que utilizará WordPress

MYSQL_USER
        ↓
Usuario de WordPress en MySQL

MYSQL_PASSWORD
        ↓
Contraseña de ese usuario




-----------------------------------------------------
Al final el comando

___mysql:8.0               ---estamos indicando la imagen que docker debe utilizar   es decir Mysql




despues creaos el contenedor wordpress

sudo docker run -d \
  --name wordpress \
  --network wordpress-net \
  -p 8080:80 \
  -e WORDPRESS_DB_HOST=wordpress-db:3306 \
  -e WORDPRESS_DB_USER=wordpress \
  -e WORDPRESS_DB_PASSWORD=... \
  -e WORDPRESS_DB_NAME=wordpress \
  wordpress:latest
